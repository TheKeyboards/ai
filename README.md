# Image Tagger（数据集图片打标工具）

这是一个纯前端、本地运行的图片打标工具，适合给训练数据集做标签整理。

## 功能

- 拖拽/选择多张图片
- 内置常见标签分类（人设、画风、风格、构图、光照、场景）
- 自定义标签模板（新增分类/标签）
- 按图片逐张勾选标签
- 支持备注
- 导出 `annotations.json`
- 复制当前图标签并批量粘贴到全部图片

## 1 分钟上手

### 1) 启动本地页面

在项目目录执行：

```bash
python3 -m http.server 8000
```

然后浏览器打开：

```text
http://localhost:8000
```

> 不需要安装前端依赖，不需要后端服务。

## 使用步骤（核心）

### 步骤 1：上传图片

- 把图片直接拖到页面顶部“上传图片”区域。
- 或点击上传区域，手动选择多张图片。

### 步骤 2：设置/维护标签模板（可选）

- 页面会显示默认标签模板。
- 想新增标签：输入“分类名 + 标签名”，点击“添加标签”。
  - 例如：分类 `服装`，标签 `kimono`。
- 想回到初始模板：点击“重置默认模板”。

### 步骤 3：逐张打标

- 左侧列表点击某张图片。
- 右侧会显示该图片预览。
- 在下方分类区勾选标签。
- 在“备注”中可填写附加说明（例如角色名、特殊要求）。

### 步骤 4：批量复用标签（提高效率）

- 在一张图上先选好标签。
- 点击“复制当前图标签”。
- 点击“粘贴到全部图片”即可批量套用。

### 步骤 5：导出结果

- 点击“导出 JSON”，会下载 `annotations.json`。
- 文件包含：`filename`、`tags`、`notes`。

---

## 导出格式示例

```json
[
  {
    "filename": "girl_001.png",
    "tags": ["female", "anime", "masterpiece"],
    "notes": "可选备注"
  }
]
```

## 数据安全说明

- 工具完全本地运行，图片不会上传到外网。
- 标签模板存储在浏览器 `localStorage`。

## 常见问题

### Q1：关闭页面后，图片为什么没了？

图片文件本身不会被网页长期保存，刷新/关闭后需要重新导入；
但你新增的模板标签会保留在本地浏览器中。

### Q2：导出的 JSON 怎么用于训练？

可在后续脚本中把 `tags` 转成训练框架需要的文本格式（如 `txt/jsonl/csv`）。

### Q3：能不能按你的数据集字段再扩展？

可以，建议下一步加：
- 多种导出格式（`txt/jsonl/csv`）
- 标签搜索与快捷键
- 标签权重/优先级
- 自动打标模型接口（可选）
